# Завдання 3. Порівняння ефективності алгоритмів сортування

Скрипт `main.py` сортує випадковий масив цілих чисел (від 0 до 100000) трьома способами і вимірює час виконання через `timeit`:

- **Insertion Sort** - сортування вставками, O(n²);
- **Merge Sort** - сортування злиттям, O(n log n);
- **Timsort** - вбудований `sorted()` в Python, O(n log n) у найгіршому випадку.

Кожен замір виконано 10 разів (`number=10`), тому в таблиці наведено сумарний час для 10 запусків.

## Результати

| Розмір масиву | Insertion Sort | Merge Sort | Timsort |
|---------------|----------------|------------|---------|
| 100           | 0.00198 с      | 0.00127 с  | 0.00004 с |
| 1000          | 0.19933 с      | 0.01683 с  | 0.00049 с |
| 10000         | пропущено      | 0.21590 с  | 0.00860 с |

Insertion Sort на розмірі 10000 не запускався, бо для квадратичного алгоритму це занадто довго.

## Висновки

- **Insertion Sort** - найповільніший, O(n²), непридатний для великих масивів.
- **Merge Sort** - O(n log n), на 1000 елементів у ~12 разів швидший за Insertion Sort.
- **Timsort** (`sorted`) - найшвидший у всіх випадках.

**Висновок:** для практики використовувати `sorted()`.
